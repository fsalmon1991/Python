# RustChain Human Funnel — Stage 1 Awareness Asset Pack

Prepared for `Scottcjn/rustchain-bounties#315` by `@fsalmon1991`.

The creative direction is deliberately human-first: nostalgia for machines people already know, rebellion against disposable-upgrade culture, and a very easy first step. It avoids price promises, investment language, autonomous-agent framing, and claims that someone will make money.

## 10 ready-to-post hooks / captions

### 1. The computer you were told was obsolete
**Best for:** X / Shorts caption / TikTok caption

**Copy:**
> That old computer in the closet is not automatically useless. Before you recycle it, give it one more job. RustChain is an experiment built around the idea that older real hardware should still have a reason to run.

**CTA:** See what your machine reports: `pip install clawrtc` → run the miner in dry-run mode first.

**Formatting note:** Pair with a clean photo of an older laptop opening beside a modern one. No earnings figures on screen.

---

### 2. Keep the machine. Change the job.
**Best for:** X / vertical-video caption

**Copy:**
> Upgrade culture says: replace the machine. A better question is: can the machine do a different job? Proof of Antiquity starts there — identify real hardware, recognize its age, and put existing computers back to work.

**CTA:** Read the project before installing anything: https://github.com/Scottcjn/Rustchain

**Formatting note:** Three short lines on screen: `KEEP IT.` / `REPURPOSE IT.` / `RUN IT.`

---

### 3. A tiny rebellion against e-waste
**Best for:** X / TikTok / Shorts

**Copy:**
> You do not need a brand-new GPU to experiment with a blockchain project. If you already own an old laptop or desktop, that is the point. Reuse first. Upgrade only when you actually need to.

**CTA:** Try the safe first step: run the RustChain miner in dry-run mode and inspect what it detects.

**Formatting note:** Use a real desk, one old machine, one power cable, no crypto imagery.

---

### 4. Remember when a computer lasted ten years?
**Best for:** nostalgia post

**Copy:**
> Remember when a computer became *your* computer — scratches, stickers, a noisy fan, the keyboard you knew by feel? Some of those machines still work. RustChain treats hardware age as something worth measuring instead of something to hide.

**CTA:** Dust one off, boot it, and see whether it can still do useful work.

**Formatting note:** Warm close-up of worn keyboard / stickered lid. Keep the tone personal, not technical.

---

### 5. Start without committing to anything
**Best for:** onboarding post

**Copy:**
> Curious, but not ready to leave software running? Good. Do the boring thing first: install, run a dry test, read the output, then decide. No hype required.

**CTA:** `pip install clawrtc` and use the documented dry-run path before mining.

**Formatting note:** Terminal screenshot with the words `TEST FIRST` large above it.

---

### 6. Your old laptop does not need a comeback story
**Best for:** X / Shorts caption

**Copy:**
> It does not have to beat a new workstation. It only has to be useful again. That is a much more interesting goal than pretending old hardware is secretly faster than new hardware.

**CTA:** Explore how RustChain's Proof of Antiquity treats physical hardware identity and age: https://github.com/Scottcjn/Rustchain

**Formatting note:** Split screen: `FASTER?` crossed out; `USEFUL AGAIN?` checked.

---

### 7. Before you buy another machine
**Best for:** short-form caption

**Copy:**
> Before buying hardware for a weekend experiment, ask one question: what do I already own? A spare desktop, an old ThinkPad, a Mac that still boots — start there.

**CTA:** Test existing hardware first. Keep the experiment zero-cost.

**Formatting note:** Show a shopping-cart icon fading out, then a closet / shelf machine powering on.

---

### 8. Old silicon still has a voice
**Best for:** brand / concept post

**Copy:**
> Most compute systems reward whoever brings the newest or biggest hardware. Proof of Antiquity asks a different question: can a network recognize *what physical machine is actually participating* and give older hardware a reason to stay useful?

**CTA:** Read the source, inspect the rules, then form your own opinion: https://github.com/Scottcjn/Rustchain

**Formatting note:** Avoid token-price graphics. Use silhouettes of different computer generations.

---

### 9. The 10-minute test
**Best for:** easy-start challenge

**Copy:**
> Give an old computer ten minutes. Boot it. Open a terminal. Check Python. Run a dry test. If it is annoying, stop. If it works, you just found a new use for something you already owned.

**CTA:** Try the 10-minute test tonight.

**Formatting note:** Simple checklist graphic: `BOOT` → `TERMINAL` → `DRY RUN` → `DECIDE`.

---

### 10. Reuse is more interesting than nostalgia
**Best for:** X / closing campaign post

**Copy:**
> Keeping old hardware only as decoration is nostalgia. Giving it a real workload is reuse. That is the part worth testing.

**CTA:** Pick one working machine you already own and see whether RustChain can recognize it.

**Formatting note:** End with the machine on and doing visible work, not sitting on a shelf.

# Posting / formatting guidance

- **X:** Hooks 1–10 work as standalone text with one image. Do not add token-price hashtags or earnings language.
- **TikTok / Shorts:** Keep text overlays under ~8 words per card. Let the physical machine be the visual proof.
- **Thumbnails / static posts:** Use original photos, generated backgrounds, or simple vector shapes that the publisher owns. Avoid copyrighted meme photography.
- **CTA hierarchy:** `test what you own` first, repo/install second. The campaign should feel like an invitation to experiment, not a financial promise.
- **Accessibility:** Burn captions into every short and preserve high text/background contrast.
