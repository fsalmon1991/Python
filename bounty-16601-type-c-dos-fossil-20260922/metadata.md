## Short description
RustChain’s public DOS Miner “Fossil Edition” targets 8086/286/386/486/Pentium DOS systems, documents a 640 KB conventional-memory minimum, publishes CPU-era antiquity multipliers, and provides an offline `ATTEST.TXT` workflow.

Source reviewed: https://github.com/Scottcjn/rustchain-dos-miner

This is an AI-assisted, source-checked package. It describes an experimental open-source network and makes no guarantee of token value, profit, or attestation acceptance.
