## Description

RustChain’s public documentation describes a hardware-attestation flow that collects system information, runs six hardware checks, creates a fingerprint, signs the payload with Ed25519, submits it to `/attest/submit`, checks for duplicate hardware, and records an antiquity multiplier for valid enrollment.

This short explains that flow without treating the multiplier as a CPU benchmark or guaranteed earnings rate.
