# Script — “Every Machine Becomes Vintage”

**Target:** 50–55 seconds  
**Word count:** 108 words  
**Format:** vertical short, ≤60 seconds

## Hook

**What if an older computer could carry more protocol weight than a newer one?**

## Narration

What if an older computer could carry more protocol weight than a newer one? RustChain does exactly that. Its current README lists a PowerPC G4 from 2003 at 2.5x, while modern x86_64 is listed at 0.8x. Not because the G4 is faster: Proof of Antiquity rewards verified hardware age and preservation.

The same README illustrates a Ryzen 9 moving from 0.8x in 2026 to 1.3x in 2031, 1.8x in 2036, and 2.2x by 2041.

RustChain says hardware identity is checked through six signals, including clock drift, cache timing, SIMD identity, thermal entropy, instruction jitter, and anti-emulation.

The idea: make longevity part of protocol value. Every machine becomes vintage.
