## Description

RustChain’s public RIP-200 node code assigns the `vax` architecture a 3.5x **base antiquity multiplier**. That is a reward-weight input, not a promise of 3.5x earnings: the protocol time-ages antiquity weights and still applies eligibility/attestation logic before epoch rewards are allocated. Block-producer selection is separately described as deterministic round-robin — one CPU, one vote.

Source code and claim map are included in this package.
